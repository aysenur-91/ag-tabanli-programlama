AFTERCREDİTS

Proje Hakkında

Aftercredits, kullanıcıların dizi dünyasını keşfetmesini ve izleyebilecekleri yeni yapımlar hakkında fikir edinmesini amaçlayan bir web sitesi projesidir.

Bu proje, Ağ Tabanlı Programlama dersi kapsamında geliştirilmektedir.

Kullanılan Teknolojiler
- HTML: Web sayfasının yapısını oluşturmak için kullanılmıştır.
- CSS: Web sayfasının renklerini, yazı biçimlerini ve tasarımını düzenlemek için kullanılmıştır.

Mevcut Özellikler
- Aftercredits başlık alanı
- Dizi tanıtım kartları
- Koyu mavi ağırlıklı renk teması
- Görseller ve metinlerle oluşturulmuş web arayüzü

Proje Dosyaları
- `index.html`: Web sayfasının yapısı
- `stil.css`: Web sayfasının tasarımı
